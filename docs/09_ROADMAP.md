## Phase 1: Foundation

**Цель:** Подготовить базу проекта.

**Задачи:**

### 1.1 Инфраструктура
- Создать Git-репозиторий
- Настроить окружения (dev, staging, production)
- Настроить CI/CD (GitHub Actions)
- Подключить Vercel или выбранный хостинг
- Настроить БД (PostgreSQL на Supabase)
- Настроить файловое хранилище (Cloudflare R2 / DigitalOcean Spaces)
- Настроить CDN (Cloudflare)

### 1.2 Базовая архитектура проекта
- Инициализировать Next.js проект
- Настроить TypeScript
- Настроить ESLint + Prettier
- Настроить Tailwind CSS
- Настроить Prisma
- Создать базовую структуру папок
- Настроить env variables
- Создать базовую схему БД (Prisma schema)

### 1.3 Аутентификация (Admin)
- Реализовать JWT auth
- Создать Login/Logout API
- Защитить `/admin/*` маршруты
- Создать Auth middleware

**Приоритет:** Высокий  
**Зависимости:** Нет  
**Оценка:** 1 неделя

**Цель:** Реализовать управление автомобилями.

### 3.1 Vehicle CRUD (Admin)

- Форма создания автомобиля
- Форма редактирования автомобиля
- Загрузка фото/видео
- Drag-and-drop сортировка фото

### 3.2 Financial Engine
- Централизованный модуль расчёта цен
- Интеграция курсов валют
- Автоматический расчёт totalCost

### 3.3 Vehicle Inspection

- Загрузка фото по категориям (кузов, двигатель и т.д.)

## Phase 6: Leads & Orders

**Цель:** Реализовать заявки и управление заказами.

### 6.1 Leads API
- POST /leads (создание заявки)
- Валидация
- Сохранение в БД
- Telegram-уведомление (обезличенное)

### 6.2 Leads Forms (Public)
- Форма "Подобрать автомобиль"
- Форма "Рассчитать стоимость"
- Валидация (React Hook Form + Zod)
- Success message

### 6.3 Orders Management (Admin)
- GET /admin/orders (список заказов)
- GET /admin/orders/:id (детальный просмотр)
- PATCH /admin/orders/:id/status (изменение статуса)
- POST /admin/orders/:id/timeline (добавление событий)
- Таблица заказов с фильтрами
- Детальная страница заказа
- Управление timeline

**Приоритет:** Высокий  
**Зависимости:** Phase 2  
**Оценка:** 2 недели

## Phase 13: Production Deployment

**Цель:** Запуск production-версии.

### 13.1 Pre-launch Checklist
- [ ] Все критические функции работают
- [ ] QA завершён
- [ ] Security audit пройден
- [ ] HTTPS настроен
- [ ] Домены настроены (zakazavto.ru, admin.zakazavto.ru)
- [ ] DNS настроен
- [ ] SSL сертификаты установлены
- [ ] Резервное копирование настроено
- [ ] Мониторинг настроен (Sentry, uptime monitoring)
- [ ] Политика конфиденциальности опубликована
- [ ] Юридическая проверка 152-ФЗ (если требуется)
- [ ] Контент загружен (реальные автомобили, отзывы, кейсы)
- [ ] Виталий добавлен (фото, текст)
- [ ] Telegram-бот настроен
- [ ] Analytics подключена

### 13.2 Deployment
- Deploy на production
- DNS переключение
- Smoke testing
- Мониторинг ошибок (первые 24 часа)

### 13.3 Post-launch
- Мониторинг производительности
- Мониторинг ошибок
- Сбор обратной связи
- Hotfix критических багов

**Приоритет:** Критический  
**Зависимости:** Phase 1-12  
**Оценка:** 2 дня

## Итоговая оценка MVP

**Фазы 1-13:** ~12-14 недель (3-3.5 месяца) при наличии 1-2 разработчиков full-time.

**Критический путь:** Phases 1 → 2 → 3 → 4 → 5 → 6 → 8 → 11 → 12 → 13

**Можно распараллелить:**
- Phase 7 (Reviews & Cases) — параллельно с Phase 5-6
- Phase 9 (Content Pages) — параллельно с Phase 5-7
- Phase 10 (Telegram) — параллельно с Phase 7-9
