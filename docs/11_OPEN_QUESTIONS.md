## Важные (влияют на функционал)

### ВВ-001: Публичность цен

**Вопрос:** Показывать ли цены автомобилей публично на сайте?

**Варианты:**
1. Показывать всем (как у конкурентов)
2. Не показывать (только по запросу)
3. Показывать только итоговую цену
4. Показывать с детализацией расходов

**Влияние:** Карточки автомобилей, детальные страницы, API.

**Текущее решение:** Архитектура поддерживает оба варианта (поле `showPricePublic`). Решение принять перед production.

---

### ВВ-002: Главный CTA

**Вопрос:** Какой главный призыв к действию?

**Варианты:**
- "Подобрать автомобиль"
- "Оставить заявку"
- "Получить консультацию"
- "Рассчитать стоимость"

**Влияние:** Hero, CTA-секция, кнопки по сайту.

**Временное решение:** Использовать "Подобрать автомобиль", можно изменить позже.

---

### ВВ-003: Сроки доставки

**Вопрос:** Какие точные сроки доставки из каждой страны?

**Известно:** "Доставка от 2 недель" (у конкурентов)

**Не известно:**
- Япония: X недель
- Корея: Y недель
- Китай: Z недель
- По России: W недель

**Влияние:** Блок "Как проходит заказ", страница "Доставка".

**Временное решение:** Не указывать конкретные сроки до получения точных данных.

---

### ВВ-004: Детализация финансов в публичном заказе

**Вопрос:** Показывать ли клиенту детализацию расходов в публичном tracking?

**Варианты:**
1. Показывать полную детализацию (цена авто + доставка + таможня + комиссия)
2. Показывать только итоговую стоимость
3. Показывать после подтверждения клиента
4. Не показывать публично

**Влияние:** Страница отслеживания заказа.

**Текущее решение:** Архитектура поддерживает гибкость, решение принять перед реализацией Phase 8.

---

### ВВ-005: Формат отзывов

**Вопрос:** Какой формат отзывов предпочтителен?

**Варианты:**
1. Текст + фото клиента с автомобилем
2. Текст + видео-отзыв
3. Только текст
4. История (клиент → задача → автомобиль → результат → отзыв)

**Влияние:** Структура Review в Data Model, UI компоненты.

**Текущее решение:** Поддерживаем все форматы, приоритет — реальные истории (вариант 4).

**Для coding AI:**

1. Если вопрос **критический** и блокирует задачу — остановиться и запросить решение
2. Если вопрос **важный** и есть временное решение — использовать временное решение, зафиксировать TODO
3. Если вопрос **второстепенный** — использовать разумное стандартное решение, зафиксировать в коде комментарием
