# Prompt 01: TypeScript-типы

Создай `src/types/components.ts` с экспортируемыми интерфейсами `SocialLink`, `Founder`, `WorkStep`, `FAQItem`, `Manager`, `ManagerCategory`, `ExternalReview` и `OfficeHours`.

Требования:
- Используй точные поля и union-типы из `docs/ARCHITECTURE_REDESIGN.json`.
- Для внешних ссылок используй `url: string`; не добавляй лишнюю бизнес-логику.
- Добавь короткие JSDoc-комментарии только там, где они помогают понять назначение поля.
- Не изменяй другие файлы.
- После изменения выполни `npm run lint`.
