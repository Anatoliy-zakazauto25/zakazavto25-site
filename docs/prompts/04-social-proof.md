# Prompt 04: SocialProof

Создай `src/components/features/social-proof.tsx` с props `{ links: SocialLink[] }`.

Компонент отображает заголовок «Социальные сети» и карточки ссылок с платформой и количеством подписчиков.

Требования:
- Импортируй `SocialLink` из `@/types/components`.
- Рендери данные через `.map`, не дублируй разметку.
- Все внешние ссылки: `target="_blank"` и `rel="noreferrer"`.
- Обеспечь клавиатурный focus, читаемые подписи и адаптивную сетку.
- Сохрани визуальный язык `globals.css`; не используй emoji как единственную доступную подпись.
