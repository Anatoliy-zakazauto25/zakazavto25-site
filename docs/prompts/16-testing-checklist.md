# Prompt 16: Финальная проверка

Проведи финальную проверку проекта.

Выполни:

1. `npm run lint`
2. `npm run build`
3. Запусти `npm run dev` и проверь `/`, `/catalog`, `/cases`, `/about`, `/request` и `/privacy`.
4. Проверь якоря `/#advantages`, `/#faq`, `/#reviews`, `/#contacts`.
5. Проверь FAQ с клавиатуры и screen-reader атрибуты.
6. Проверь телефонные и внешние ссылки.
7. Проверь ширины 360px, 430px и desktop, отсутствие горизонтального скролла.
8. Проверь, что topbar не дублируется на страницах и admin-маршрутах.

В отчете укажи выполненные проверки, ошибки и файлы, которые пришлось исправить. Не помечай задачу выполненной при падающем lint/build.
