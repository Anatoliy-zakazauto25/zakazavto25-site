# Prompt 06: WorkSteps

Создай `src/components/features/work-steps.tsx` с props `{ steps: WorkStep[]; showCTA?: boolean }`.

Отобрази переданный массив этапов, рассчитанный на 9 элементов: номер, заголовок и описание. При `showCTA` покажи ссылку «Оформить заявку» на `/request`.

Требования:
- Импортируй `WorkStep` из `@/types/components`.
- Не зашивай девять шагов в компонент.
- Поддержи мобильную одну колонку и desktop-сетку/timeline.
- Используй существующие классы кнопок и секций либо добавь минимальные CSS-правила в отдельном шаге.
- Проверь lint.
