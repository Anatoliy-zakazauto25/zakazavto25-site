# Prompt 03: SiteTopbar

Создай `src/components/layout/site-topbar.tsx`.

Компонент `SiteTopbar` без props должен показывать адрес `г. Владивосток, ул. 13-я Рабочая, 12с3` и внешнюю ссылку «Открыть в 2ГИС» на подтвержденный URL компании.

Требования:
- Используй семантический `header`/`div` и обычный `<a>` для внешней ссылки.
- На мобильном адрес можно скрыть, ссылка должна оставаться доступной.
- Согласуй классы с существующей темной темой и CSS-подходом проекта.
- Не подключай новую UI-библиотеку.
- Проверь lint.
