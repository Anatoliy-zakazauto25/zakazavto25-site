# Prompt 14: CSS

Проверь `src/app/globals.css` после интеграции. Добавь только недостающие правила для topbar, FAQ, managers, trust block и smooth scroll.

Требования:
- Следуй существующим CSS-переменным, брейкпоинтам и именованию.
- Не добавляй Tailwind `@apply`, если текущая конфигурация/файл его не использует корректно.
- Обеспечь `:focus-visible`, контраст и отсутствие горизонтального overflow на 360px.
- Проверь desktop и mobile правила.
- Запусти `npm run lint` и `npm run build`.
