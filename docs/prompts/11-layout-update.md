# Prompt 11: Layout

Проверь `src/app/layout.tsx` и реши, где должен находиться `SiteTopbar`.

Требования:
- Не рендери topbar дважды. Если он добавлен в layout, убери его из страниц, где он уже используется.
- Не показывай публичный topbar в admin/login layout, если группировка маршрутов этого не позволяет.
- Сохрани metadata, шрифты и текущие providers.
- Убедись, что `lang="ru"` сохранен.
- Проверь build.
