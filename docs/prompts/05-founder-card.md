# Prompt 05: FounderCard

Создай `src/components/features/founder-card.tsx` с props `{ founder: Founder }`.

Покажи фото, имя, должность и необязательное описание основателя. Используй `next/image` только с корректными `fill`/`sizes` либо фиксированными размерами.

Требования:
- Импортируй `Founder` из `@/types/components`.
- Для отсутствующего фото предусмотрь доступный визуальный fallback без падения рендера.
- Не добавляй несуществующий файл изображения как обязательную зависимость без проверки.
- Карточка должна быть адаптивной и вписываться в существующий блок преимуществ.
