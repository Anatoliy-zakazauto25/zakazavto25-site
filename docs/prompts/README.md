# Промты для GPT-5.6 Luna

Выполнять файлы по порядку от `01` до `16`. Перед каждым шагом прочитать `docs/ARCHITECTURE_REDESIGN.json`, `AGENTS.md` и целевые файлы проекта.

После каждого шага:

1. Проверить импорты и типы.
2. Запустить `npm run lint`.
3. Не заменять существующий дизайн произвольными Tailwind-классами, если уже есть соответствующий стиль в `src/app/globals.css`.
4. Не использовать реальные персональные данные менеджеров без подтверждения владельца сайта.

Порядок: типы и данные, компоненты, интеграция, layout и навигация, стили, privacy и финальная проверка.
